# FairShare — Dynamic Split-Bill Settlement Optimizer

FairShare is a frontend-based group expense tracker that helps users manage shared expenses and settle debts among group members.

The project aims to reduce the **number of transactions** required to settle debts using a greedy max-creditor/max-debtor matching approach.

## How to Run

No server or installation is required. You can open the project directly in a browser or use the Live Server extension in VS Code.

1. Open `index.html` to view the FairShare landing page.
2. Click **Get Started** or **Open FairShare** to access `login.html`.
3. Register a new account or log in with an existing account.
4. After successful login, you will be taken to `dashboard.html`.
5. Create a group, add members, enter expenses, review balances, and manage settlements.

## Pages

- `index.html` — Landing page and product overview
- `login.html` — User registration and login
- `dashboard.html` — User dashboard and group selection
- `group.html` — Group overview and statistics
- `members.html` — Add and remove group members
- `expense.html` — Add and split expenses
- `ledger.html` — View and manage expenses
- `balances.html` — View member balances
- `settlement.html` — Settlement plan and payment history
- `profile.html` — User profile and logout

## Technologies Used

- HTML
- CSS
- Vanilla JavaScript

## Project Objective

FairShare simplifies group expense management by tracking shared expenses, calculating individual balances, and helping group members settle debts with fewer transactions.
